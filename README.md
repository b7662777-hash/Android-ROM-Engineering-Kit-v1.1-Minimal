# Android ROM Engineering Kit

A lightweight toolkit for Android ROM development, recovery work, device bring-up, and ROM engineering experiments.

## What it is

Android-ROM-Engineering-Kit is a practical collection of scripts and helpers for working with Android source trees, device trees, kernels, recoveries, images, and build workflows.

The project is focused on making ROM engineering tasks easier to reproduce and automate without hiding what is happening underneath.

## Current focus

- Android ROM build workflows
- Device tree and kernel development
- Recovery and image tooling
- Build and packaging helpers
- ADB/Fastboot workflow automation
- ROM engineering experiments

## Status

Early development. APIs, scripts, and project structure may change.

## Who is it for?

This project is aimed at Android developers, ROM maintainers, device bring-up developers, and people learning how Android system software is assembled.

## Contributing

Issues and pull requests are welcome. If you find a reproducible problem, include the device, Android version, command used, and relevant build output.
